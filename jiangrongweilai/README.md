# 匠融未来 非遗数字经营工作台

## 使用与部署

双击 index.html 即可打开，推荐在目录运行 `python -m http.server 8082` 后访问 http://localhost:8082。

上传本目录全部文件至 GitHub 仓库根目录，在 Settings → Pages 中选择 Deploy from a branch、main、/ (root)，保存即可。也可以放在已有站点的 jiangrong/ 子目录。不要只上传压缩包。无需安装依赖、无需编译，全部资源为相对路径。

## 功能

经营总览、订单文本规则提取、人工确认、批次工序排程、增员/交期情境、逐周现金流、尾款延期与材料涨价模拟、工序打卡、收款状态记录、现金流CSV导出、经营材料JSON快照。全部业务状态保存在浏览器 localStorage。

## 报告依据与假设

依据《匠融未来》报告的100件芦苇画、30天交付、40%预付款案例。单价800元、单件材料300元、人工240元、其他40元及工序时间为可修改的补充演示假设，不是报告中的实际经营数据。

生产采用20件一批、7工序、独立人员池的流水排程。每个日历日可工作6小时，扣除已有任务占用比例。按交期排序计算新订单，不宣称最优排程。默认已有原料覆盖首批，第2周为后续补采。新增装裱工每人每天200元，计入情境人工成本。全部订单从统一计划起点测算。

现金流按周计算，30天属于第5周。尾款在要求交期与排产完成日的较晚时间后到账；延迟情境继续后移。最大资金缺口是相对安全线的缺口，并非建议贷款额。周末净额可能遗漏周内先支后收的压力，8周外收支会提示。阶段回款是假设客户同意的新付款条件，不是保证。进度和收款打卡保存状态，但不改写原始计划曲线；本版用于原始计划复盘，不是实时账户余额。

## 范围

这是独立可部署前端演示，不是正式工行产品，没有真实OCR、大模型、银行账户、支付或授信接口。规则提取只识别明确字段并要求人工确认。没有登录鉴权、服务器数据库、加密存储或多设备同步。不要输入真实敏感合同或个人信息。原报告和团队信息不包含在部署包内。

融资资料只保存和下载到本机，不发送给银行。金融决策由银行独立审核。图像为AI生成情境摄影。

## 文件

index.html 页面外壳；style.css 视觉与响应式；model.js 计算与示例数据；views.js 页面；app.js 交互；assets/craft.png 情境图片。修改示例数据及规则请编辑 model.js。
